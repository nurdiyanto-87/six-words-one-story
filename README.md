A make.fun entry for **Six Words, One Story** — one complete story told in exactly six words.

`main.py` (pure Python standard library, deterministic) writes the story to `/output/entry.txt`:

> He proposed. She laughed. He stayed.

Run it with:

```sh
python3 main.py
```

The story is written to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
